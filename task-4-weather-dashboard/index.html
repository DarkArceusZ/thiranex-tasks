About This Application

This weather dashboard uses the Open-Meteo API, a free and open-source weather API that requires no API key.

Features:

  • Real-time weather data for any city worldwide
  • Current temperature and conditions
  • Detailed weather metrics (humidity, wind, pressure, UV index)
  • Responsive design for all devices
  • No API key required

Data source: Open-Meteo
